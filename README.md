# Homebrew tap

Homebrew formulae maintained by cakeholeDC.

## Available formulae

### [chromaticli](https://github.com/cakeholeDC/chromaticli)

Sync terminal colors with VSCode workspace themes. See the upstream repository for usage.

Install and configure shell integration:

```sh
brew install cakeholeDC/tap/chromaticli
chromaticli install
```

Restart your shell after installation.

Remove shell integration before uninstalling the package:

```sh
chromaticli uninstall
brew uninstall cakeholeDC/tap/chromaticli
```
